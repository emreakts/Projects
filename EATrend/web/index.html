3. YouTube

Onayladığın bölümler gizli yüklenir ve planlanan saatte YouTube kendisi yayınlar. Bilgisayarın o saatte kapalı olsa da yayın çıkar.

"invalid_client" hatası alırsan
  • Client ID mutlaka .apps.googleusercontent.com ile biter. API anahtarı ya da Secret değildir.
  • İstemci türü Web uygulaması olmalı (Masaüstü uygulaması değil).
  • Yetkili yönlendirme URI'sine aynen http://localhost:3000/oauth/google/callback eklenmiş olmalı.
  • Kimlik bilgisini oluşturduktan sonra birkaç dakika beklemek gerekebilir.
  • Önce Kaydet'e bas, sonra "Google ile bağlan".
Client ID nasıl alınır?
  1. console.cloud.google.com → yeni proje oluştur.
  2. "YouTube Data API v3"yi etkinleştir.
  3. OAuth onay ekranını kur (Harici, kendi e-postanı test kullanıcısı ekle).
  4. Kimlik bilgileri → OAuth istemci kimliği → Web uygulaması. Yetkili yönlendirme URI'si: http://localhost:3000/oauth/google/callback
  5. Çıkan Client ID ve Secret'ı buraya yapıştır.
Google, doğrulanmamış API projelerinden yüklenen videoları gizli tutabilir. Videoların herkese açılması için YouTube'un API denetim başvurusunu yapman gerekebilir. Bağlantı çalışsa da bu aşamada videolar gizli kalırsa sebep budur.
